# 如何裁剪模板

仓库里故意不附带任何按钮图片。模板必须从你自己的 Last Z 客户端、在你实际游玩的分辨率和界面缩放下裁出来。别人的截图、手绘按钮或缩放过的图片都不能用，分数会对不上，还可能点错位置。

助手只在你选中的游戏窗口客户区里寻找这张小图，找到并连续确认后，点击它的中心。

## 裁之前先固定环境

后面每次运行都要保持这些条件不变。变了就要重新裁。

1. 固定 Windows 显示缩放（例如 100%、125% 或 150%，选一个之后不要改）。
2. 固定游戏分辨率、窗口化/无边框模式，以及游戏里的界面缩放。
3. 用你平时玩的语言界面。按钮上是「联盟帮助」就裁这四个字的样子，不要裁别的语言。
4. 用即将用来运行助手的那台显示器。把游戏窗口放在这块屏幕上。

助手进程会按监视器 DPI 感知启动，截图像素和点击坐标才能对齐。模板也必须是这个状态下的原始像素，不要再放大或缩小。

## 领取资源

1. 打开游戏，走到能稳定看到「领取资源」按钮的界面。主界面上这个按钮通常比联盟帮助容易摆出来，适合先用来确认匹配和点击。
2. 用 `Win + Shift + S` 截取这一小块，不要截整屏。
3. 在画图里把选区裁到按钮本身。可以带上一圈不变的按钮边，但不要带上资源数量、倒计时、闪光，或会变的背景。
4. 若画面上同时有多个很像的领取按钮，多带一点只有你要点的那一个才有的边框，避免点到旁边那个。点中一个后要等冷却结束，才会再找下一次。
5. 另存为 PNG。不要用 JPEG。

## 联盟帮助

1. 打开游戏，走到能稳定看到「联盟帮助」按钮的界面。
2. 用 `Win + Shift + S` 截取游戏窗口里的这一小块，不要截整屏。
3. 在画图里把选区裁到按钮本身。可以带上一圈不变的按钮边，但不要带上会动的背景、人数、倒计时或闪光。
4. 若按钮有按下/悬停/冷却几种样子，裁你希望被点击的那一种静止样子。
5. 另存为 PNG。不要用 JPEG，压缩痕迹会让分数晃动。

## 不要放进模板的东西

- 整张游戏画面，或超过客户区大约四成的大图。大模板很容易误匹配。
- 边长小于 8 像素的图。程序会直接拒绝。
- 带透明通道的装饰。读取时会去掉透明通道，边缘可能发灰。请裁不透明的按钮区域。
- 动画的某一帧，除非那一帧会在画面上停留到连续两次扫描都看得到。

## 放到助手里试跑

1. 启动助手，选择游戏主窗口（选标题对应的那个，截取的是它的客户区，不是整个屏幕）。
2. 「领取资源」和「联盟帮助」各自点「浏览…」，选中对应的 PNG。不用的动作取消「启用」。
3. 保持勾选「演练（只记录不点击）」。
4. 把游戏窗口放到前台，并且不要被别的窗口挡住。助手截的是屏幕上这一块看得见的像素，不是游戏内部画面。
5. 看日志里的分数。稳定高于阈值（默认 0.85）再考虑取消演练。
6. 分数一直偏低：阈值先不要降到 0.80 以下。先检查分辨率、缩放、遮挡，以及模板是不是裁多了会变的区域。确认环境一致后重新裁一张更紧的图。
7. 分数偶尔窜高但位置不对：模板不够独特。带上一点只有这个按钮才有的边框，或把阈值调高。

扫描间隔建议 0.4 到 0.8 秒。太快会占 CPU，太慢则按钮闪一下就错过。程序要求连续至少两帧都匹配到同一位置附近，才会进入点击前的窗口检查。
