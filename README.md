# Last Z 助手

这是一个给 **Last Z 电脑版** 用的外部小工具，当前只有两件事：

1. 在你选中的游戏窗口里找到「联盟帮助」按钮并点击。
2. 发现断线弹窗时点击「重连」。

它只做屏幕截图上的模板匹配，以及一次普通的鼠标左键点击。窗口、阈值、间隔和演练开关都在自带的 Tk 界面里设置。

## 请先读：规则风险和技术边界

使用任何自动点击都**可能违反游戏的用户协议**。后果可能包括功能限制或封号，由使用者自己承担。这个程序不提供规避检测的方法，也不能降低这种风险。

建议始终先打开 **演练**。演练只把“将要点哪里”写进日志，不会移动鼠标。确认连续多次的位置都在游戏窗口内，再取消演练。

本工具明确不做这些事：

- 不读取游戏进程内存
- 不注入 DLL，不修改游戏文件
- 不抓包，不构造或重放协议
- 不绕过反作弊，不隐藏进程，不伪装输入来源

点击时能看到鼠标移动。这是正常的系统鼠标操作，不是后台隐身点击。PyAutoGUI 的角落保险也开着：把鼠标甩到屏幕四个角，点击会立刻停。

## 环境

- Windows 10 或 Windows 11
- Python 3.11 或更新版本
- 游戏窗口可见，并且在自动点击期间保持为前台窗口
- 模板 PNG 由你自己从当前客户端裁剪，仓库不附带模板

Linux 和 macOS 只能跑单元测试。真正操作窗口的入口会直接退出。

## 安装

在仓库目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install .
```

`pywin32` 只在 Windows 上安装。版本写在 `pyproject.toml` 里：NumPy 2.5.x、OpenCV 5.0.x、MSS 10.x、PyAutoGUI 0.9.54、pywin32 312。

启动：

```powershell
lastz-assistant
```

也可以：

```powershell
python -m lastz_assistant
```

请用上面这个虚拟环境里的 Python 启动。程序会在创建窗口之前声明每监视器 DPI 感知，让截图像素和点击坐标一致。不要再用另一个没经过这个入口的方式去 `import` 之后才补 DPI。

游戏如果以管理员身份运行，这个助手也要以同一权限运行，否则 Windows 不允许它向游戏窗口点击。能都不用管理员就都不用。

## 准备模板

看 [templates/README.md](templates/README.md)。两张 PNG 都要从你自己的游戏画面裁，裁完放到任意目录，在界面里选中。不要把整屏截图当模板。

## 使用

1. 打开助手。默认勾着「演练（只记录不点击）」。
2. 点「刷新」，在列表里选中 Last Z 的主窗口。程序只截这个窗口的客户区，也只在这个客户区里计算点击位置。
3. 为「联盟帮助」和「断线重连」分别选择模板。暂时不用的动作取消「启用」。
4. 阈值默认：联盟帮助 0.85，断线重连 0.88。扫描间隔默认 0.6 秒，可在 0.2 到 30 秒之间改。
5. 每个动作有自己的冷却（默认 5 秒和 8 秒）。点过一次后，在冷却结束前不会再点。
6. 确认游戏在前台且没有被别的窗口挡住，点「开始」。
7. 看日志里的分数和演练坐标。稳定后停止，取消演练，再开始。
8. 「暂停」只是不再扫描，热键仍然有效。「停止」会结束线程并释放 F12。
9. 紧急停止按 **F12**。F12 只在自动点击运行期间被占用，停止或关闭窗口后会释放。关闭窗口时会停掉后台线程并注销热键。

匹配要连续至少两帧落在差不多同一位置，才会进入点击。点击前会再看一次：窗口还在、没有被最小化、位置和大小没变、并且仍是前台。任何一条不满足都不会点。窗口消失、模板损坏、截图失败或截图尺寸和客户区对不上时，界面会显示错误并停机。

设置写在当前工作目录的 `lastz-assistant-settings.json`。里面只有路径、阈值和窗口标题，没有截图。

## 它怎么工作

```text
界面线程（Tk）
  选择窗口、模板、阈值、间隔、演练
  开始 → 注册 F12，启动后台线程
  定时从队列取出日志，更新状态

后台线程
  确认目标窗口存在且在前台
  用 MSS 截取该窗口客户区
  用 OpenCV 对每个启用的动作做模板匹配
  连续两帧确认 → 再次确认窗口和前台 → 演练则只记录，否则 PyAutoGUI 点击中心
```

两个动作不是两段独立的点击代码。它们是 `src/lastz_assistant/catalog.py` 里的两条配置：名称、说明、默认阈值、默认冷却、确认帧数。引擎按这份目录工作。

以后若要增加动作，在该元组里追加一条 `ActionSpec`，准备对应模板即可。不要把新的游戏功能写进匹配或点击实现里。当前目录只有联盟帮助和断线重连。

## 限制

- 只认屏幕上看得见的像素。游戏被挡住、缩到最小、或不在前台时不会点。置顶窗口若盖住游戏，即使游戏是前台，也可能匹配到盖住的内容；请保持客户区无遮挡。
- 模板必须和当前分辨率、Windows 缩放、游戏界面缩放一致。改了其中任何一项都要重裁。
- 客户区截图尺寸若和窗口矩形不一致，会当作 DPI 坐标错位并停机，避免点到别的程序。
- 按钮若和界面上别的控件长得很像，可能点在错误的那个上面。把模板裁得更独特，或提高阈值。
- 扫描有间隔，闪得很快的按钮可能凑不齐连续两帧。
- F12 在运行期间会被本程序登记为全局热键，游戏里的 F12 此时不会再收到。
- 界面日志由主线程刷新，大约每 100 毫秒一次。后台线程不直接改控件。

## 开发与测试

核心状态机不依赖 Windows。截图、窗口和鼠标都是接口，测试使用假实现。

```powershell
python -m pip install -e ".[dev]"
python -m ruff format --check .
python -m ruff check .
python -m pytest
```

在 Windows 上还需要实机看这些事：DPI 模式是否为 `per-monitor-v2`、选中的是否为游戏主窗口、演练坐标是否落在按钮中心、取消演练后是否只点中游戏、F12 和关闭窗口后热键是否释放。
